# Modifier le site Maison Floriane

Guide pour Flore. Tout se fait dans l'administration du site (`/wp/wp-admin/`), sans toucher au code.

## Où modifier quoi

| Je veux changer… | Où |
|---|---|
| Le logo, le slogan | **Maison Floriane › Identité** |
| L'e-mail, le téléphone, le numéro WhatsApp, les délais de réponse | **Maison Floriane › Coordonnées** |
| Les liens TikTok, Instagram, Facebook | **Maison Floriane › Réseaux sociaux** |
| La bande en haut de toutes les pages | **Maison Floriane › Bandeau** |
| Les 4 arguments (livraison, paiement, retours, conseil) | **Maison Floriane › Réassurance** |
| Le bas de page, les logos de paiement affichés | **Maison Floriane › Pied de page** |
| Les messages WhatsApp préremplis | **Maison Floriane › Messages WhatsApp** |
| Les textes communs aux fiches produit (atouts, délai d'expédition, livraison) | **Maison Floriane › Fiches produit** |
| La page « introuvable » | **Maison Floriane › Page introuvable (404)** |
| L'accueil : titre, vidéos, produits présentés, avant/après, étapes, questions fréquentes, lettre | **Pages › Accueil** |
| Ma lettre (Mon histoire), la page Contact, l'en-tête de la Boutique | **Pages › Mon histoire / Contact / Boutique** |
| Prix, promo, stock, nom, description, photos d'un produit | **Produits › le produit** (cadres WooCommerce) |
| Étape du rituel, accroche, quand/où, contenance, ingrédients, conseils, vidéo, contenu du duo | **Produits › le produit › Fiche Floréa** |
| La description d'une image (lue par les malvoyants et Google) | **Médias › l'image › Texte alternatif** |
| Les liens des menus | **Apparence › Menus** |
| La petite icône de l'onglet du navigateur | **Réglages › Général › Icône du site** |
| Le formulaire de contact, la lettre Floréa (champs, destinataire, inscrits) | **Forminator** |
| Le titre et la description affichés dans Google | **Yoast SEO**, en bas de chaque page et produit |

## Petites règles à connaître

- **Doré** : dans un titre, entourez un ou plusieurs mots d'astérisques pour les mettre en doré. Exemple : `Moi, c'est *Flore*.`
- **Retour à la ligne** : un retour à la ligne dans un titre est conservé sur le site.
- **Masquer un élément** : videz le champ. Le texte, le bouton ou le bandeau disparaît du site. Pour le faire revenir, retapez un texte.
- **Images et vidéos** : choisissez-les dans la médiathèque. Pour une vidéo, ajoutez aussi une image d'aperçu, affichée pendant le chargement.
- **Le duo** : sur la fiche du duo, « Composé de » liste les soins qu'il contient. Vendre un duo retire aussi ces soins du stock, et le duo passe en rupture dès qu'un de ces soins l'est.

## Version anglaise

Le site est traduit par **TranslatePress**. Quand vous modifiez un texte en français, sa traduction anglaise est à refaire :

1. Ouvrez la page sur le site, puis cliquez sur **Traduire la page** dans la barre noire du haut.
2. Cliquez sur le texte modifié et saisissez sa version anglaise.
3. Enregistrez.

Tant que ce n'est pas fait, la version anglaise affiche le texte en français.

## Bon à savoir

Vos modifications sont conservées : les mises à jour techniques du site (`composer seed`) ne les écrasent pas. Elles ne remplissent que les champs vides.
